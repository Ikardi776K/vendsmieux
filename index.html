Questions fréquentes

Faut-il un compte ?

Non. La formule gratuite fonctionne sans compte. Un compte permet de retrouver vos annonces plus facilement.

L’IA est-elle connectée ?

Tant qu’aucune clé API n’est configurée, l’application tourne en mode démonstration : le texte est construit à partir de vos informations, sans intelligence artificielle, et c’est clairement indiqué.

Le prix proposé est-il fiable ?

Non, c’est une indication. Comparez toujours avec les annonces vendues sur la plateforme visée.

Mes données sont-elles envoyées quelque part ?

En mode démonstration, tout reste dans votre navigateur.
